# דשבורד בחירות 26

האתר הציבורי: https://moshelavi.github.io/elections-26-dashboard/

## עדכון לכולם

1. פותחים את האתר ולוחצים על הסלוגן משמאל.
2. מזינים מפתח GitHub מסוג fine-grained, שהוגבל למאגר הזה עם הרשאת **Contents: Read and write**, ולוחצים על התחברות.
3. מעלים את CSV של הכנסת ה־26. התוצאות מפורסמות בקובץ `shared-results.json`.
4. לשינוי מצב ספירת הכפולות מסמנים/מבטלים ולוחצים על פרסום מצב הספירה.

המפתח אינו כלול בקוד ואינו נשמר באחסון הדפדפן. אין להזין אותו בצ׳אט או לשמור אותו במאגר. הוא נשאר בזיכרון החלון עד יציאה מניהול או רענון. גם אם אדם אחר פותח את חלון העדכון, GitHub אינו מאפשר לו לשנות תוצאות ללא הרשאת כתיבה.

הצופים בודקים תוצאות חדשות מדי 30 שניות וכשחוזרים ללשונית. מטמונים של GitHub או ניתוק רשת עשויים לעכב את ההופעה; שעת העדכון היא שעת פרסום התוצאות, ולא שעת הבדיקה. אין צורך להעלות קובץ אצל כל צופה או לרענן את הדף.

## מבנה

- `elections_dashboard_26_v15.html` — הדשבורד, כולל התמונות, הגופנים ונתוני בסיס.
- `shared-sync.js` — קריאה ציבורית, הרשאת מנהל ופרסום התוצאות ל־GitHub.
- `shared-results.json` — המקור המשותף והמעודכן של הנתונים ושל מצב ספירת הכפולות.
- `index.html` — כניסה מקישור האתר הראשי.

החישוב היחסי של מנדטים והערכת המעטפות הכפולות אינם חלוקה רשמית. נתוני הכנסת ה־25 כבר מוטמעים. נתוני CSV מאוגדים לפי סמל יישוב ונבדקים לפני פרסום. תוצאות משותפות קודמות אינן נדרסות אם קריאת הקובץ או הפרסום נכשלו. כל שינוי ציבורי נשמר בהיסטוריית Git.
